# Data profile

Generated by `python -m heart.eda`. All statistics use the de-duplicated data.

## Shape and cleaning

- Raw rows: **1025**, columns: **14**
- Exact duplicate rows removed: **723**
- Unique patients kept: **302**
- Missing values in raw file: **0**
- Invalid category codes set to missing: `{'ca': 4, 'thal': 2}`
